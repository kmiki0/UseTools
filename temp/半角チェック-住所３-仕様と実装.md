# 半角文字チェック＆全角"■"変換 仕様書

## 概要

CSVファイルの特定カラム（住所３等）に対して、半角文字が紛れ込んでいた場合に全角の「■」に1対1置換する処理。

## 背景・目的

- 住所３カラムは**完全に全角のみ許容**するルール
- 誤って半角が混入するケースがあるため、検出＆変換が必要

## 対象環境

| 項目 | 内容 |
|---|---|
| 言語 | VB.NET |
| CSVエンコーディング | Shift_JIS |
| ヘッダー行 | なし |
| カラム特定方法 | 位置固定（インデックス指定） |

## 半角文字の定義

| 分類 | Unicode範囲 | 例 | 変換対象 |
|---|---|---|---|
| 半角英大文字 | `U+0041`〜`U+005A` | A B C ... Z | ✅ 対象 |
| 半角英小文字 | `U+0061`〜`U+007A` | a b c ... z | ✅ 対象 |
| 半角数字 | `U+0030`〜`U+0039` | 0 1 2 ... 9 | ✅ 対象 |
| 半角記号（ASCII） | `U+0021`〜`U+002F` 等 | ! @ # - / ( ) | ✅ 対象 |
| 半角カナ | `U+FF61`〜`U+FF9F` | ｱ ｲ ｳ ﾞ ﾟ ｰ | ✅ 対象 |
| 半角スペース | `U+0020` |   | ⏸️ 保留 |
| 制御文字 | `U+0000`〜`U+001F` | タブ、改行等 | ❌ 対象外 |

## 判定ロジック

Shift_JISにおけるバイト数で全角・半角を判定する。

- **Shift_JISで1バイト → 半角 → 全角「■」に置換**
- **Shift_JISで2バイト → 全角 → そのまま**

※ Shift_JISでは全角文字はすべて2バイトのため、この判定で正確に動作する。
※ UTF-8の場合は全角が3〜4バイトになるため、この判定方式は使えない点に注意。

## 関数仕様

| 項目 | 内容 |
|---|---|
| 関数名 | `ConvertHanToMark` |
| 引数 | `value As String`（対象文字列） |
| 戻り値 | `String`（変換後文字列） |
| 処理 | 1文字ずつ走査し、半角なら「■」に1対1置換 |
| Null/Empty | そのまま返却 |

## 実装コード

```vb
''' <summary>
''' 文字列中の半角文字を全角"■"に置換する
''' （半角スペース・制御文字は対象外）
''' </summary>
Public Function ConvertHanToMark(value As String) As String
    If String.IsNullOrEmpty(value) Then Return value

    Dim enc As System.Text.Encoding = System.Text.Encoding.GetEncoding("Shift_JIS")
    Dim sb As New System.Text.StringBuilder(value.Length)

    For Each c As Char In value
        If Char.IsControl(c) OrElse c = " "c Then
            ' 制御文字・半角スペースはそのまま
            sb.Append(c)
        ElseIf enc.GetByteCount(c.ToString()) = 1 Then
            ' 半角 → ■
            sb.Append("■"c)
        Else
            ' 全角 → そのまま
            sb.Append(c)
        End If
    Next

    Return sb.ToString()
End Function
```

## 呼び出し例

```vb
' CSV読み込み時に対象カラムに適用
Dim columns() As String = line.Split(","c)

' 住所３が3列目（インデックス2）の場合
columns(2) = ConvertHanToMark(columns(2))

' 他のカラムにも展開可能
' columns(5) = ConvertHanToMark(columns(5))
```
